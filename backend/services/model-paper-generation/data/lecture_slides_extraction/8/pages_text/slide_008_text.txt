SECURITY IN SQL SERVER
A SQL Server instance contains a hierarchical collection of entities, starting with the 
server.
Each server contains multiple databases, and each database contains a collection of 
securable objects.
The SQL Server security framework manages access to securable entities through 
authentication and authorization
Authentication : verifying the identities of users trying to connect to a SQL Server 
instance
Authorization : determines which data resources that authorized users can access and 
what actions they can take.
