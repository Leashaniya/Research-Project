FUNCTIONAL DEPENDENCIES
Mathematical definition of functional dependency (FD) :
A functional dependency, denoted by X→ Y, where X and Y are sets of attributes in 
relation R, specifies  the following constraint:
Let t1 and t2 be tuples of relation R for any given instance
Whenever t1[X] = t2[X] then t1[Y] = t2[Y]
