STORED FUNCTIONS/PROCEDURES (CONTD.)
Syntax of a function
Syntax of a procedure
CREATE FUNCTION <function name> (parameters)
CREATE PROCEDURE <procedure name> (parameters)
RETURNS <return type>
<proedure body>
<function body>
Each parameter to a procedure should have a 
data type and a parameter mode (IN or OUT).
Parameter mode of parameters for 
functions is IN which parameters allow the 
calling code to pass values into the 
procedure
IN: This is the default mode. IN parameters 
allow the calling code to pass values into 
the procedure
OUT: OUT parameters allow the 
procedure to pass values back to the 
calling code
