INTEGRITY CONSTRAINTS (CONTD.)
Referential integrity Constraint
The referential integrity constraint is specified between two relations and is used to maintain the 
consistency among tuples in the two relations.
Informally, the referential integrity constraint states that a tuple in one relation that refers to 
another relation must refer to an existing tuple in that relation.
Foreign keys enforce referential integrity constraints
Foreign key attributes in R1 referring to R2 have the following rules:
The FK attributes in R1 have the same domain(s) as the primary key attributes if R2
The value of FK in tuple t1 in R1 must reference an existing PK value in tuple t2 of R2
We can diagrammatically display the foreign keys by drawing an arrow from the foreign key to the 
primary key
