STEPS TO PROVIDE USERS WITH ACCESS TO SQL SERVER RESOURCES
1. At the server level, create a login for each user that should be able to log into SQL 
Server.
create Windows authentication logins that are associated with Windows user or group 
accounts,
create SQL Server authentication logins that are specific to that instance of SQL Server.
2. Create user-defined server roles if the fixed server roles do not meet your 
configuration requirements.
3. Assign logins to the appropriate server roles (either fixed or user-defined).
4. For each applicable server-level securable, grant or deny permissions to the logins 
and server roles.
